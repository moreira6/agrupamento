# Vila do Aprendizado

Projeto educativo infantil para Jardim 2, feito com HTML, CSS e JavaScript puro.

## Como testar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador para testar localmente.

## Como publicar no Vercel
1. Envie os três arquivos (`index.html`, `style.css` e `script.js`) para um repositório GitHub.
2. No Vercel, escolha **Add New → Project** e importe o repositório.
3. Como é um projeto estático, não precisa de build command nem de output directory.
4. Clique em **Deploy**.

## Observações
- O progresso é salvo no `localStorage` do navegador e computador usados.
- Os efeitos sonoros são sintetizados pelo próprio navegador.
- A fonte Nunito é carregada do Google Fonts; se estiver sem internet, haverá fontes alternativas.
- Esta é uma primeira versão: as atividades usam imagens emoji como apoio visual e podem ser substituídas por ilustrações próprias posteriormente.
